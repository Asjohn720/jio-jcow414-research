# Decryption Keys for JioFiber JCOW414

This folder contains the static encryption key used to decrypt and encrypt configuration backups (`.enc` files) for Sercomm JCOW414 on firmware version R2.15 (and earlier).

* **`JCOW414.key`**: 16-byte static passphrase:
  `BE F2 26 75 7C B1 49 CB 04 CD CA 84 DC 5B E9 55`
